# Café Boreal S.R.L. - Cloud Computing Project

## Descripción
Proyecto integrador de Computación en la Nube para Café Boreal S.R.L.

## Estructura
- `source/` - Código fuente de APIs, frontend y módulo legado
- `deploy/` - Manifiestos K8s, configuración Nginx y scripts
- `docs/` - Documentación técnica
- `evidence/` - Capturas de pantalla y evidencias

## Tecnologías
- Kubernetes (Minikube)
- Docker
- PostgreSQL
- Nginx
- Apache + PHP (módulo legado)
- Prometheus + Grafana + Loki
